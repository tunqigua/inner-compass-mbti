# 向内生长

一个可中断、可回看，也允许「不确定」的 24 题人格偏好体验。

- 在线体验：https://tunqigua.github.io/inner-compass-mbti/
- 项目仓库：https://github.com/tunqigua/inner-compass-mbti
- 完整案例说明：[CASE-STUDY.md](CASE-STUDY.md)

## 产品能力

- 24 个日常情境，约 4 分钟完成
- 每题选择后立即保存在当前浏览器
- 再次进入时恢复到第一个未完成题目
- 完成后可集中回看并修改答案
- 接近中点、单维持平、多维持平和完全均衡四类边界状态
- 结果可保存或通过不含逐题答案的链接分享
- 桌面、平板和手机响应式布局
- 键盘操作、焦点管理和减少动效支持

## 隐私与边界

逐题答案不会上传。未完成进度和上次结果保存在当前浏览器，可由用户随时清除；完成后会删除逐题草稿，只保留四维结果。

这是一项用于自我观察的交互体验，不是经过心理测量验证的专业量表，也不用于诊断、招聘、职业选择或重大人生决策。

MBTI 为注册商标，本体验与其官方机构无关联。

## 本地查看

直接打开 `index.html` 即可使用。推送到 `main` 分支后，GitHub Actions 会自动发布到 GitHub Pages。
