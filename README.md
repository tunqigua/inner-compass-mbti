# 向内生长｜MBTI 自我探索网站

这是一个可直接打开的完整静态网站，不需要安装软件或注册账号。

- 在线访问：https://tunqigua.github.io/inner-compass-mbti/
- 项目仓库：https://github.com/tunqigua/inner-compass-mbti

## 如何查看

双击 `index.html`，即可在浏览器中打开。

推送到 `main` 分支后，GitHub Actions 会自动发布到 GitHub Pages。

## 已包含

- 沉浸式首页与原创“雾中林径”主视觉
- 16 种人格卡片、四组筛选与完整详情弹窗
- 24 道情境式题目、答题进度、返回修改与本机进度保存
- E/I、S/N、T/F、J/P 四维结果可视化
- 深度结果解读、分享与重新测试
- 3 篇自我探索短文
- 桌面、平板与手机响应式布局
- 键盘焦点、减少动效、文字化图表与移动端触控适配

## 隐私与边界

答案只保存在当前浏览器的本机存储中，不会上传。测试用于自我探索，不构成心理诊断，也不适合用于招聘、医疗或其他高风险决策。

MBTI 为注册商标。本体验与其官方机构及 16Personalities 无关联，题目、文案、昵称与视觉素材均为本项目原创。
