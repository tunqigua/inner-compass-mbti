# 向内生长

一个可中断、可回看，也允许「不确定」的 24 题人格偏好体验。

- 在线体验：https://tunqigua.github.io/inner-compass-mbti/
- 项目仓库：https://github.com/tunqigua/inner-compass-mbti
- 完整案例说明：[CASE-STUDY.md](CASE-STUDY.md)

## 产品能力

- 24 个日常情境，约 4 分钟完成
- 每题选择后立即保存在当前浏览器
- 再次进入时恢复到第一个未完成题目
- 完成后可集中回看并修改答案
- 答题时只有随进度加深的中性雾层，提交后光点绽开、雾散人物显影
- 使用本机字体，避免远程字体加载后的字形闪换
- 总分持平时参考两侧非中立回答次数，并明确标注中点参考；次数也持平时保留均衡
- 接近中点、单维持平、多维持平和完全均衡四类边界状态
- 结果可保存或通过不含逐题答案的链接分享
- 桌面、平板和手机响应式布局
- 键盘操作、焦点管理和减少动效支持

## 隐私与边界

逐题答案不会上传。未完成进度和上次结果保存在当前浏览器，可由用户随时清除；完成后会删除逐题草稿，只保留四维结果及平分时的次数差信息。新分享链接保留这些汇总信息，旧版分享链接仍可打开。

这是一项用于自我观察的交互体验，不是经过心理测量验证的专业量表，也不用于诊断、招聘、职业选择或重大人生决策。

MBTI 为注册商标，本体验与其官方机构无关联。

## 本地查看

直接打开 `index.html` 即可使用。推送到 `main` 分支后，GitHub Actions 会自动发布到 GitHub Pages。

## 验证

运行 `node --test tests/scoring.test.cjs` 检查评分、边界状态、旧版兼容和分享校验。每维六题、五档等概率回答的穷举模型中，四维至少一维无法判定的比例从 37.84% 降至 23.27%；这是合成模型的规则对比，不代表实际用户比例或测量准确率。


## 数据与版本

- 本机数据保存在 `inner-compass-mbti:*` 命名空间；旧版 `ic-*` 键会在首次打开时自动迁移并删除，避免与其他站点争用同名键。
- 题库文案调整会升级题目版本（当前 `24q-v2`），上一版保存的结果不再复用，避免用旧题解释新分。
- `node --test tests/scoring.test.cjs` 已在部署工作流中执行，测试失败不会发布。
